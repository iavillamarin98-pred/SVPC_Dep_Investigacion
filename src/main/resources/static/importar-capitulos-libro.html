Importación y cálculo de puntajes de capítulos de libro

Reglas aplicadas para capítulos de libro:
  • Autor de capítulo: 5 puntos base.
  • Coautor de capítulo: 3 puntos base.
  • Autor solo: recibe el 100%.
  • Autor + 1 coautor: autor 60%, coautor 40%.
  • Autor + 2 o más coautores: autor 50%, coautores comparten el otro 50%.
  • Solo coautores: se divide el puntaje base de coautor entre todos los coautores.
